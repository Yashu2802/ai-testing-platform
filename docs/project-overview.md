
# AI-Powered Testing Platform

## Overview
An AI-powered testing platform that uses Generative AI
to simplify software testing activities.

## Key Features
- AI-based test case generation
- Positive and negative test scenarios
- Excel export
- Playwright automation integration
- Automated execution reporting

## Technology Stack
- TypeScript
- Ollama
- Qwen 2.5 3B
- Playwright
- Node.js
