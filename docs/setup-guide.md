
# Setup Guide

## Prerequisites
- Node.js
- TypeScript
- Ollama
- Qwen 2.5 3B
- Playwright

## Installation

Install project dependencies:

npm install

Initialize Playwright:

npm.cmd init playwright@latest

Install Chromium:

npx.cmd playwright install chromium

## Run Tests

npx.cmd playwright test

## View Report

npx.cmd playwright show-report
